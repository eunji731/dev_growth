# TIL
## java

1. Files
	``` java
Files.copy(file.getInputStream(), uploadPath.resolve(storedFileName + "." + fileExtension));
	```

	`resolve()` 
	- 경로(Path)에 하위 경로를 붙이는 메서드
	- 단순 문자열 `"C:/uploads/" + fileName` 조립이 아니라 **`Path` 객체 기준으로 운영체제에 맞게 경로를 합쳐준다**는 점
	- 파일 경로 만들 때는 문자열 `+`로 붙이는 것보다 `resolve()` 쓰는 게 정석
	- *`file`의 내용을 InputStream으로 읽어서, `uploadPath` 폴더 안에 `storedFileName.fileExtension`이라는 이름으로 복사*
		```java
		uploadPath = Path.of("C:/uploads");
		storedFileName = "abc123";
		fileExtension = "jpg";
		
		uploadPath.resolve("abc123.jpg")
		
		// => C:/uploads/abc123.jpg 
		```
